# InkRAG · 轻量 RAG 知识库管理平台

> 自托管的轻量 RAG 知识库管理平台：文档解析、父子切分、混合检索、三屏联动、文档版本管理、系统运维、备份恢复与对外接入口（入库 API / Dify 兼容层 / MCP Server）。
